# PLANO MESTRE — IA 1: DIREÇÃO VISUAL DO HEXÁPODE

## 1. Meta

Construir uma biblioteca gráfica médica de **600 ativos principais**, reutilizáveis e versionáveis, mantendo identidade visual única para todos os projetos do ecossistema Hexápode.

O plano parte de uma matriz conceitual de **200 temas**, organizada em 20 gerações históricas de 10 conceitos. Cada conceito será desenvolvido em três camadas visuais:

1. **camada canônica** — estrutura, anatomia ou mecanismo essencial;
2. **camada aprofundada** — variações, detalhes, comparações e falhas;
3. **camada aplicada** — uso clínico, decisão, procedimento, exercício ou composição didática.

Portanto:

```text
200 conceitos × 3 camadas = 600 ativos
600 ativos ÷ 10 ativos por ciclo = 60 ciclos de geração
```

Cada ciclo é autocontido, revisável e versionável.

---

## 2. O Hexápode como ecossistema

Respira e Ventila são o ponto de partida histórico, mas o acervo não pertence exclusivamente nem majoritariamente a eles.

A biblioteca deve servir a:

- Respira;
- Ventila;
- Cardio;
- ECG;
- Hemodinâmica;
- Trauma;
- Ultrassom;
- Nefrologia;
- Neurologia;
- Farmacologia;
- Emergências;
- Pediatria;
- Infectologia;
- Anatomia;
- Fisiologia;
- demais braços futuros do Projeto Hexápode.

O objetivo não é produzir 600 cartazes isolados. É construir um **design system médico**, com componentes que possam ser recombinados em milhares de páginas, exercícios, animações, interfaces e materiais clínicos.

---

## 3. Regra de triplicação

Para cada conceito de número `N` na matriz original:

| Camada | Intervalo | Função |
|---|---:|---|
| A — Canônica | `001–200` | representação essencial e reutilizável |
| B — Aprofundada | `201–400` | detalhe, variação, comparação, erro ou fisiopatologia |
| C — Aplicada | `401–600` | caso, decisão, intervenção, exercício ou composição clínica |

A correspondência é direta:

```text
conceito 001 → ativos 001, 201 e 401
conceito 002 → ativos 002, 202 e 402
...
conceito 200 → ativos 200, 400 e 600
```

### Exemplo

```text
015 — Alvéolo canônico
215 — Alvéolo aprofundado: pneumócitos, surfactante e microarquitetura
415 — Alvéolo aplicado: recrutamento, colapso e consequência clínica
```

Essa arquitetura preserva a matriz original e impede que a expansão para 600 se transforme em uma lista arbitrária.

---

## 4. Organização dos 60 ciclos

### Fase A — Ativos canônicos

- ciclos `G001–G020`;
- ativos `001–200`;
- correspondem à matriz original abaixo.

### Fase B — Ativos aprofundados

- ciclos `G021–G040`;
- ativos `201–400`;
- repetem a mesma ordem conceitual da Fase A;
- aprofundam anatomia, mecanismo, variações, erros, limites e comparações.

### Fase C — Ativos aplicados

- ciclos `G041–G060`;
- ativos `401–600`;
- repetem novamente a mesma ordem conceitual;
- convertem a base em decisão clínica, procedimento, exercício, animação, fluxo ou situação aplicada.

# 6. MATRIZ DAS CAMADAS B E C

As camadas B e C não alteram a ordem dos conceitos. Elas alteram a função visual.

## 6.1 Camada B — aprofundamento

Para cada conceito, escolher pelo menos uma das seguintes operações:

- ampliação microscópica;
- corte anatômico;
- sequência temporal;
- comparação normal × alterado;
- comparação entre fenótipos;
- mecanismo passo a passo;
- erro frequente;
- limite fisiológico;
- complicação;
- relação com sistema adjacente.

### Exemplos

```text
031 Inspiração canônica
231 Inspiração aprofundada: cadeia pressão muscular → pressão pleural → fluxo

071 VCV canônico
271 VCV aprofundado: influência de resistência, complacência e fluxo

141 Noradrenalina canônica
341 Noradrenalina aprofundada: receptores, território vascular e dose-resposta
```

## 6.2 Camada C — aplicação

Para cada conceito, escolher pelo menos uma das seguintes operações:

- caso clínico;
- decisão terapêutica;
- ajuste de parâmetro;
- procedimento;
- exercício socrático;
- armadilha cognitiva;
- algoritmo;
- comparação de condutas;
- integração multissistêmica;
- animação ou interação.

### Exemplos

```text
031 Inspiração canônica
431 Inspiração aplicada: fadiga muscular e indicação de suporte

071 VCV canônico
471 VCV aplicado: ajuste inicial e interpretação das pressões

141 Noradrenalina canônica
541 Noradrenalina aplicada: vasoplegia, titulação e perfusão
```

# 10. Fluxo de produção por ciclo

Para cada conjunto de 10 ativos:

1. ler o manifesto;
2. selecionar os dez próximos itens `planned` ou `needs_revision`;
3. consultar referências visuais e bibliográficas;
4. produzir prompts canônicos;
5. gerar as dez artes-base;
6. revisar os dez renders visualmente;
7. produzir overlays exatos;
8. produzir alt texts e metadados;
9. extrair componentes reutilizáveis;
10. atualizar o manifesto;
11. integrar ou submeter ao Codex;
12. registrar o ciclo em commit ou PR.

Não iniciar o ciclo seguinte antes de registrar o estado real do ciclo atual.

---

# 11. Critérios de aceite

Cada ativo deve passar por:

```yaml
visual_identity: pass
scientific_coherence: pass
didactic_function: pass
anatomical_coherence: pass_or_not_applicable
text_accuracy: pass
mobile_legibility: pass
component_reusability: pass
alt_text: pass
metadata: pass
decision: approved
```

Regras adicionais:

- curvas, escalas e números exatos devem ser produzidos deterministicamente;
- a imagem gerada não substitui SVG quando precisão geométrica for essencial;
- nenhum ativo pode existir apenas para preencher espaço;
- toda prancha precisa ensinar estrutura, mecanismo, comparação ou decisão;
- o mesmo componente não deve ser redesenhado sem necessidade;
- versões masculina, feminina e infantil devem permanecer compatíveis para overlays;
- o conteúdo clínico deve prevalecer sobre a ornamentação.
